# Arcee

A personal coaching system you build with an LLM. Hand the idea file to your favorite AI — Claude.ai, ChatGPT, Gemini, Cursor, Claude Code, whatever — and ask it to bootstrap a version tailored to you. By the end of the first conversation you'll have a small set of structured Markdown files (or a chat-only equivalent) and an agent that knows how to read, update, and reason against them as you work.

## Use this:

**[`idea-file_arcee.md`](idea-file_arcee.md)** — the long-form idea file. Self-contained; everything you need to bootstrap a system is in there.
